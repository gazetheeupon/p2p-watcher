    Troubleshooting
    
    
    
      Stuck on "Connecting…"
      
    Press the × Cancel button next to that connection to stop trying, then use Retry. If it keeps failing, the host's tab may have been closed, or the two networks may not be able to reach each other directly (some restrictive routers/firewalls block this) — there's no relay fallback if that happens.
    
    
    
    
    
      A video won't start playing
      
    For a .mkv/.avi file, the host has to prepare it first the first time anyone watches it — the status line will say so and show progress. That can take a while for a large file. If playback still fails after that finishes, the file's codec likely isn't one this browser can decode.
